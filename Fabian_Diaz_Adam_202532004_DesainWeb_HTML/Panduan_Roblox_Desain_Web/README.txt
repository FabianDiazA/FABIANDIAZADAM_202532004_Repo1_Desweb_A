PANDUAN MENGENAL GENRE GAME ROBLOX
Proyek praktikum Desain Web - Fabian Diaz Adam (202532004)

ISI FOLDER
- index.html        : halaman beranda
- genre.html        : penjelasan genre dan tabel perbandingan
- favorit.html      : formulir genre favorit
- images/roblox-avatar.svg : ilustrasi lokal yang dipakai di halaman beranda

CARA MENJALANKAN
1. Ekstrak folder ZIP.
2. Buka index.html menggunakan browser.
3. Gunakan menu navigasi untuk membuka halaman lain.

CATATAN
- Semua halaman memakai Semantic HTML dasar: header, nav, main, dan footer.
- Link antarhalaman memakai relative path.
- Website dibuat tanpa CSS sesuai ketentuan praktikum.
- Formulir bersifat statis. Tidak ada backend/database; tombol submit hanya menunjukkan mekanisme formulir HTML dasar.
- Sebelum laporan dikumpulkan, buka setiap halaman dan ambil screenshot hasil aktual. Beri watermark NIM_NAMA pada setiap screenshot sesuai ketentuan asisten.
